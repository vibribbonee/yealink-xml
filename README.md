# Yealink XML Browser

[![Add to Home Assistant Marketplace](https://my.home-assistant.io/badges/marketplace_repository.svg)](https://my.home-assistant.io/redirect/marketplace_repository/?owner=vibribbonee&repository=yealink-xml&category=integration)

Control Home Assistant entities from the XML browser on a compatible Yealink desk phone.

## Setup

Install the integration through the Home Assistant Marketplace using the button above, or copy `custom_components/yealink_xml` into Home Assistant’s `custom_components` directory. Restart Home Assistant, then open **Settings → Devices & services → Add integration**. Choose Yealink XML Browser, select the entities to expose, and open the integration’s menu URL on the phone.

For an upgrade, keep the existing integration entry so Home Assistant retains its configuration.
