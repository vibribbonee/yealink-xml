# Yealink XML Browser

Control selected Home Assistant entities from a compatible Yealink desk phone’s XML browser.

[![Add to Home Assistant Marketplace](https://my.home-assistant.io/badges/marketplace_repository.svg)](https://my.home-assistant.io/redirect/marketplace_repository/?owner=vibribbonee&repository=yealink-xml&category=integration)

Install from Home Assistant Marketplace and restart Home Assistant. Then go to **Settings → Devices & services → Add integration → Yealink XML Browser**. Choose the entities to expose and open the integration’s menu URL on the phone. Keep your existing entry when upgrading.
