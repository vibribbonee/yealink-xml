# Yealink XML Browser

Control Home Assistant entities from the XML browser on a compatible Yealink desk phone.

## Setup

Install the integration through HACS as a custom **Integration** repository when using a public copy, or copy `custom_components/yealink_xml` into Home Assistant’s `custom_components` directory. Restart Home Assistant, then open **Settings → Devices & services → Add integration**. Choose Yealink XML Browser, select the entities to expose, and open the integration’s menu URL on the phone.

For an upgrade, keep the existing integration entry so Home Assistant retains its configuration.
